# Colloque international — Casablanca, 6–8 novembre 2026

Site du colloque « Le Soufisme, la Paix et le Dialogue des Civilisations »,
organisé par Jamhiyatou Ansaarud-Dîn – Groupement Maroc.

Site statique trilingue FR / AR / EN : `index.html`, images dans `img/`,
documents téléchargeables dans `docs/`.

## Publication

Hébergé sur Netlify, relié à la branche `main` de ce dépôt :
chaque envoi sur `main` republie le site automatiquement.
Aucune étape de construction ; `netlify.toml` publie la racine du dépôt.

Aperçu local :

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```
